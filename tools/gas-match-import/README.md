# FC SIRIUS 試合結果取得プロトタイプ（GAS）

## この段階で行うこと

公式サイトの月別ページを取得し、スコア表記を含むテキストを候補として実行ログに出します。**Google Sheetsへの書き込み、既存データの更新、時間主導トリガーの登録は行いません。**

対象ページ（2026年6月）:
https://sc.footballnavi.jp/fcsirius/page.php?pno=2044

## 実行手順

1. Google Apps Scriptで新規プロジェクトを作成します。
2. `Code.gs` の内容を貼り付けます。
3. 関数一覧から `previewJune2026` を選択して実行します。
4. 初回は外部URLへのアクセス権限を承認します。
5. 実行ログで、候補件数と候補テキストを確認します。

## この試作の制約

- スコア表記を含む周辺テキストの抽出であり、1候補=1試合を保証しません。
- 日付・カテゴリは周辺テキストに明記されている場合だけ仮抽出します。
- チーム名、スコアの左右、勝敗、FM表記、A/Bチームの識別はまだ確定しません。
- サイトのHTML構造や表記により、候補の欠落・重複・誤検出が発生する可能性があります。
- 実行ログを人手で公式ページと照合し、抽出ルールを確定してからCSV/シートへの反映処理を追加します。

## 次に確認すること

1. 候補に公式ページの試合がどの程度含まれるか
2. 1試合が複数候補に分割されていないか
3. 日付・カテゴリ・相手チーム・スコアを安定して識別できるHTML構造があるか
4. 既存シートの `team,date,category,score,result` に安全に変換できるか

現時点では検証用の読み取り専用プロトタイプです。定期実行やシート更新には使用しないでください。
