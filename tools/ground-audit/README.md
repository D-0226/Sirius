# グラウンド情報の読み取り専用監査

## 目的
FC SIRIUS観戦ガイドのグラウンド関連データを変更せず、実データの列構成と問題候補を確認します。マスター整理・移行の前に実行してください。

## 実行手順
1. FC SIRIUSのGoogleスプレッドシートを開きます。
2. **拡張機能 → Apps Script** を開きます。
3. このファイル `Audit.gs` の内容を新しいスクリプトファイルにコピーします（既存の `Code.gs` や取込処理を置き換えないでください）。
4. 関数一覧から `auditGroundDataReadOnly` を選び、実行します。
5. 実行ログに出力されたJSONを確認します。初回はGoogleの権限承認が必要になる場合があります。

## この監査が行うこと
- スプレッドシート名とシート一覧を取得
- 各シートの行数・列数・ヘッダー候補を取得
- `grounds` 相当の列があるシートで、空の会場名と正規化後の重複候補を検出
- 緯度・経度列があるシートで、座標の欠落・数値不正・範囲外を検出
- `grounds_memo` 相当のシートでメモ列の空欄を検出
- `grounds` と `grounds_memo` のタブの存在を確認

## 安全性
この関数は `getActiveSpreadsheet()` と `getDataRange().getDisplayValues()` による読み取りだけを行います。セルへの書き込み、行の追加・削除、シートの変更、トリガー登録、外部への送信は行いません。

## 注意事項
- 同名・表記揺れ候補は自動統合しません。結果を見て人手で確認します。
- 列名の自動検出は候補語に基づくため、特殊な列名や見出し位置は手動確認が必要です。
- この監査は本番データを変更しません。結果を確認した後、別途バックアップと移行計画を用意してください。
